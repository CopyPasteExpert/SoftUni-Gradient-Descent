# Why Does Gradient Descent Slow Down?

My project looks at the quadratic bowl function and uses three optimization methods to find its minimum: Gradient Descent, Momentum and Newton's method. They are explained, and their behavior is shown through examples.

## How to run

```
pip install -r requirements.txt
```

Then open `notebook.ipynb` and choose **Run All**.

## Files

- `notebook.ipynb`: the main report, with the problem, proofs, experiments, conclusions, sources and self-assessment
- `optimizers.py`: my implementations of gradient descent, momentum and Newton's method
